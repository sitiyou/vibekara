# 核对录音与制作素材

优先使用用户提供的文件、已有工程链接及构建入口。需要找本机素材或工具时，先读本地偏好。按本次产物补缺项。录音候选会改变时序时，列出版本、时长或剪辑差异请用户选择。[本地偏好和工具复用](../../docs/preferences.md)

按本次交付核对必要素材。只有曲目信息或链接时，先定位可播放的对应录音，再收集歌词、画面或伴奏中本次确实需要的内容。[所需素材和格式](../../docs/media.md#可以提供什么) · [收集顺序](../../docs/media.md#缺少素材怎么补)

- **录音**核对曲名、歌手、发行或剪辑版本、时长和首尾。
- **歌词**从已给的歌词本、LRC 或文本开始。需补齐时可查 Karaoke Studio 的歌词搜索、LRCLIB 或其他对应来源，日语读音可用 UtaTen 核对。用实际录音确认段落、反复和读音。
- **画面**核对指定 MV 的版本、前奏和剪辑点。指定 osu! 故事板时，从谱包渲染干净画面并用谱包音轨校准。[故事板](../../docs/media.md#从谱面渲染故事板) 静态视频按用户选择或现有偏好确定底图；未指定画面时可用同发行封面。
- **人声与伴奏**已有同版独立人声时直接用于打轴分析，否则按需分离人声。交付伴奏版时使用同版官方伴奏，只有缺少官方伴奏时才采用分离伴奏。核对所选音轨与原唱时间线。[人声分离与模型](../../docs/media.md#分离人声与伴奏)

以最终原唱的开头为原曲零点。交接录音、歌词和本次所需画面或伴奏的具体路径，附来源、时长、对齐量的正负方向，以及是否已应用。存在 `production.md` 时记录到素材段。打轴阶段接收与原曲零点对齐的音轨，评审和导出可以共用同样的对齐事实。

原唱、MV 或伴奏的时间线有差异时，用 `audio-offset-finder` 测音频偏移，再用 FFmpeg 裁切或补静音。安装、偏移方向和复核步骤见[对齐音频零点和时长](../../docs/media.md#对齐音频零点和时长)。处理整轨 CUE 或下载参考媒体见[媒体准备](../../docs/media.md)。
