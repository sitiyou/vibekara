# 组织整曲制作与续作

开始新任务时，默认检查并升级按安装教程部署的 vibekara。用户要求跳过自动升级时，沿用当前版本。升级后重读要用的 Skill。 [升级步骤](../../INSTALL.md#升级)

先确认本次交付目标，再读歌曲目录的 `production.md` 和现有产物。用户未指定目录、也没有现成歌曲工程时，在 `~/.vibekara/projects/` 下为这首歌选目录。已设置 `VIBEKARA_HOME` 时用其 `projects/` 子目录。整曲默认交付可编辑 `.nto`、整曲 Hook 和 1080p60 原唱导练视频。有已核验的同版伴奏时一并交付伴奏版。单阶段请求只做该阶段需要的工作。

新项目有能定位录音的文件、链接或曲目信息即可开始。打开对应阶段前，按交付目标核对必要输入，并让素材阶段补本次缺项。[最低输入及格式](../../docs/media.md#可以提供什么)

打轴、评审或导出时，复用已核实的项目环境。首次缺少环境时，按[安装教程](../../INSTALL.md)配置共享 uv 环境。

查找额外工具、媒体库或默认样式时，先读本地 `preferences.md`。只有用户明确要求长期保存时才更新偏好。[查找和复用工具](../../docs/preferences.md#查找本机工具)

## 从素材到交付

歌词沿用默认的双行左右交替布局。用户主动要求时再调整布局。

1. **确定录音和时间零点。** 走 `vibekara-assets`，核对原唱版本、歌词和本次用到的画面或伴奏。以最终原唱开头为零点，记录每份媒体的对齐量和是否已应用。需要自动打轴的人声轨时，在此阶段准备。[素材 skill](../vibekara-assets/SKILL.md)
2. **核验并保存打轴。** 走 `namioto-nicokara` 的录音打轴流程，从参考录音和歌词开始，或打开已有 `.nto` 续修。确认工程对应所选录音，检查修改的段落和前后衔接。评审和导出读取保存后的 `.nto`，预览与导出默认统一采用 `-100 ms` 偏移（提前 100 ms 显示扫色，保证所见即所得），另记实际采用的偏移和和声渠道。
3. **制作并提交样式评审。** 根据歌词、音乐和画面设计字形、排版、色彩和动效。首次制作或改动字幕样式、动效时，默认用已保存的 `.nto` 和对齐画面发布评审。首轮的大范围多方向比选与可编辑组件库（`composition`）均作为**可选项**按需启用：用户方向开放或希望在浏览器里自行试放、拖拽组合特效时，提供多套差异方向及组件库自编辑；用户已有明确方向、要求定制细节特效（如自定义矢量导唱、粒子或 WGSL 材质）时，可直接提交定制模板（单套主打或聚焦方向的 2–3 套候选）并暴露关键细调参数，跳过组件库环节；不确定时可先简短询问用户偏好。收到「以这套继续」后，从交接事件保存的组合或选值接着细调。收到「采用这版」后保存可重建快照。用户明确要求直出或只处理打轴、素材、已采用版本时，直接执行相应阶段。[组合模板](../../kara-previwer/examples/composition_template.py) · [评审 skill](../kara-previwer/SKILL.md)
4. **构建并验收。** 从采用快照重建整曲 Hook。直出时用已核验的 `.nto` 和本次确定的模板。按请求合成视频并检查实际帧率、分辨率、音画时长和关键歌词段。交付验收后的文件和可复用构建入口。[导出 skill](../vibekara-export/SKILL.md)

只有收到准备投稿或正式投稿的请求时，才按投稿指南处理对应阶段。[投稿指南](../../docs/publishing.md)

## 从现有产物续作

核对产物是否仍对应本次的录音、打轴版本、样式和交付规格，再从所需的第一项缺失产物继续。评审进行中就恢复会话。已有采用快照但缺 Hook 时重建。已有验收 Hook、只缺视频时直接合成。缺少制作记录时可从 `accepted.json` 恢复采用版本及构建规格，再核对歌曲目录里的实际文件。

使用 `production.md` 记录实际采用的输入和阶段结果。路径优先相对歌曲目录。

- **制作范围**存本次交付目标、用户给定的样式要求和本曲例外。
- **素材**存录音版本、原曲零点、已核实文件、来源和音画对齐结果。
- **打轴**存已核验的 `.nto` 及实际需要的交付偏移和和声渠道。
- **评审**存会话链接、ID、非默认 root/port、当前版本和最后处理的用户事件 ID。采用后补记 token 和快照位置。
- **交付**存已验收文件、实际分辨率和帧率、可复用的构建入口。快照、Hook、原唱成片和伴奏成片各自以产物为准。
